# Сайт-витрина автора книг

Демо одностраничного сайта-витрины: книги, главы, эссе, стихи, конструктор подарка с калькулятором, блок под AI-приложение.

## Стек

- HTML + CSS (своя дизайн-система поверх **Bootstrap 5**, CDN)
- Vanilla JS (без фреймворков): калькулятор, черновик в `localStorage`, модалка покупки, динамические отзывы
- Шрифт Manrope (Google Fonts), палитра: тёплый бежевый + глубокий синий

## Как запустить

Нужен только браузер и интернет (Bootstrap/шрифты с CDN):

```bash
# вариант 1: просто открыть файл
index.html

# вариант 2: локальный сервер
npx serve .
```

## Как устроены заявки

Все формы (заказ подарка, покупка главы, подписка, оценка AI, отзыв) идут через одну функцию `sendLead(type, payload)` в `js/script.js`:

- `LEAD_ENDPOINT = ""` — демо-режим: успех + запись в консоль;
- вставить URL (FormSubmit / Formspree / свой API) — формы начнут слать туда без переделки кода.

Оплата (ЮKassa) и автовыдача файлов подключаются на боевом этапе с ключами заказчика — в коде для этого оставлена точка `data-pay` → модалка `buyModal`.
